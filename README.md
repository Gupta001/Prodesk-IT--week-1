# Prodesk IT Internship – Week 1

This project is developed as part of **Week 1 Internship Task** during my internship at **Prodesk IT**.  
The objective of this task is to understand the basics of **frontend web development** using core web technologies.

---

## 📌 Project Description

This is a simple and responsive frontend website created using **HTML, CSS, and JavaScript**.  
The project focuses on clean UI design, basic interactivity, and responsiveness.

It also includes a **Light Mode / Dark Mode toggle** feature implemented using JavaScript.

---

## 🎯 Objectives of the Project

- Understand HTML structure and semantic elements  
- Apply CSS for layout, styling, and responsiveness  
- Use JavaScript for DOM manipulation and interactivity  
- Learn basic project structuring  
- Get hands-on experience with Git and GitHub  

---

## 🛠️ Technologies Used

- **HTML5**  
  Used to create the structure of the web page.

- **CSS3**  
  Used for styling, layout, responsiveness, and dark mode design.

- **JavaScript (ES6)**  
  Used to add interactivity such as theme toggle functionality.

---

## ✨ Features

- Responsive navigation bar  
- Light and Dark mode toggle 🌙☀️  
- Clean and minimal user interface  
- Hover effects and smooth transitions  
- Mobile-friendly design
